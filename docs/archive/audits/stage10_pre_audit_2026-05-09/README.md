# Stage 10 Pre-Audit Artifacts

These files are pre-Stage-10 audit artifacts for the Driver Drowsiness Detection repository.

They are not model outputs. They are not training results. They are only used to document repository state before implementing runtime eye ROI consistency testing.

The files under `repo_snapshot/` contain repository structure snapshots. The original noisy snapshot files were moved here from the project root and may include local or untracked development directories. They should not be used as the canonical project structure.

Prefer the clean snapshot files:

- `repo_snapshot/repo_file_list_clean.txt`
- `repo_snapshot/repo_dir_list_clean.txt`
- `repo_snapshot/repo_tree_clean.txt`

The files under `codex_audit/` contain the Codex Stage 10 pre-audit report and small supporting grep/dependency/file-existence artifacts.
