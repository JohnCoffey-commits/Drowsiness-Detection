# Documentation Map

This folder keeps the project documentation grouped by purpose.

## Main Project Docs

- `PROJECT_STRUCTURE.md`: repository structure, modules, and file map
- `PROJECT_CURRENT_STATUS.md`: current project state, claim boundaries, and main evidence
- `AI_PROJECT_CONTEXT.md`: detailed handoff context for the current VisionGuard system
- `DEPLOYMENT_RUNBOOK.md`: external-access demo runbook for the SystemUI branch
- `DAILY_STARTUP_CHECKLIST.md`: short local startup checklist
- `LOCAL_BACKEND_ARCHIVE.md`: local backend archive behavior and data boundary

## Stage Notes

Stage-level implementation notes are under:

- `stages/stage10/`
- `stages/stage13/`
- `stages/stage14/`
- `stages/stage15/`
- `stages/stage17/`
- `stages/stage18/`

These files are useful for tracing how the prototype was built, but the current entry points are still `PROJECT_STRUCTURE.md` and `PROJECT_CURRENT_STATUS.md`.

## Learning Guides

Technical learning notes are under `tech_learning/`. These are longer explanations for understanding the codebase and preparing for discussion or presentation.

## Final Report And Presentation

- `final/`: final report source, generated PDFs, and report figures
- `presentation/`: presentation HTML, assets, screenshots, and exports

## Archive

`archive/` contains older stage snapshots, stale early reports, root-level stage README files, and process audit notes. These files are kept for traceability but are not the main reading path for submission.
