# Goal 3 release checklist

- [x] Scope starts at the complete existing application baseline.
- [x] Original tests remain and new boundary tests pass locally.
- [x] Private assets, videos, databases, environments and local logs are ignored.
- [x] Scoped lint/format/type checks and frontend build pass locally.
- [x] Dependencies are pinned and actual audit findings are recorded.
- [ ] Real GitHub Actions jobs pass on the final reviewed commit.
- [ ] Both images build and run on the recorded architecture.
- [ ] Model readiness and actual authorized-video inference pass in containers.
- [ ] Stop/start and container recreation preserve archive records and outputs.
- [ ] A clean clone of an exact commit passes documented checks and full flow.
- [ ] Image IDs, sizes, build durations and original logs are retained.
- [ ] Student operations and understanding are demonstrated.
- [ ] Human peer feedback is received and addressed.
- [ ] Final evidence pack is rendered and inspected.
- [ ] Student confirms personal reflection and actual learning hours.

No automatic PR merge, public deployment, model/video publication or Canvas submission is performed. Branch protection is not changed by this checklist.
