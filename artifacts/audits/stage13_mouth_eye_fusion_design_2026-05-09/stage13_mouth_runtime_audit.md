# Stage 13 Mouth/Yawn Runtime Audit

Date: 2026-05-09

## Purpose

This audit checks whether the repository already contains runtime mouth/yawn inference outputs that can be synchronized with the Stage 12 eye alert timelines for true mouth-eye fusion validation.

This is a read-only audit of existing repository state. It does not train a model, modify checkpoints, or create final drowsiness accuracy claims.

## Search Scope

Searched source, documentation, reports, artifacts, and non-checkpoint output metadata while ignoring:

- `.git/`
- `.venv/`
- `.venv-stage10/`
- `dataset/`
- `data/`
- `SystemUI/`
- `outputs/**/checkpoints/`
- `__pycache__/`
- `.ipynb_checkpoints/`
- `*.pt`, `*.pth`, `*.zip`

## Findings

### 1. Python runtime mouth/yawn inference pipeline

**Result: Not found.**

The repository contains mouth/yawn preprocessing and training-era code, including:

- `src/preprocessing/generate_yawdd_mouth_crops.py`
- `src/preprocessing/precompute_yawdd_mouth_crops.py`
- `src/data/verify_yawdd_mouth_crops.py`
- `src/training/train_classifier.py`
- `src/training/run_initial_baselines.py`

The runtime package currently contains Stage 10, Stage 11, and Stage 12 eye-side scripts only. No Python runtime script was found that takes a full video and emits timestamped `p_yawn` values.

### 2. Selected mouth/yawn checkpoint usable locally

**Result: Not confirmed.**

Project documentation indicates that the YawDD/YawDD+ Dash mouth/yawn specialist was completed and that Stage 7 selected a ResNet18-style mouth/yawn model. However, this audit did not find a local runtime-ready selected mouth/yawn checkpoint path plus loader equivalent to the Stage 10 eye checkpoint path.

This means Stage 13 cannot currently perform verified local mouth/yawn inference on A/B/C/D videos.

### 3. Existing `p_yawn` timelines for A/B/C/D

**Result: Not found.**

Searches for `p_yawn`, `yawn_event`, `recent_yawn_event`, and mouth/yawn temporal prediction CSVs found conceptual documentation references, but no per-video timeline files for:

- `A_normal_open_baseline`
- `B_realistic_drowsy_simulation`
- `C_mild_head_motion`
- `D_controlled_long_open_closed`

### 4. Synchronized mouth-eye timelines for A/B/C/D

**Result: Not found.**

The repository contains Stage 10 eye ROI predictions and Stage 12 eye alert timelines, but no synchronized mouth-eye timeline that combines real `p_yawn` and real `p_eye_closed` values on the same timestamps or frame indices.

### 5. Missing before true synchronized fusion validation

True synchronized mouth-eye fusion validation still requires:

1. A runtime mouth/yawn inference script for full-frame videos.
2. A verified local mouth/yawn checkpoint and matching preprocessing metadata.
3. Timestamped `p_yawn` predictions for the same A/B/C/D videos.
4. A mouth ROI runtime consistency check comparable to Stage 10 eye ROI validation.
5. Alignment of mouth and eye timelines by timestamp or frame index.
6. Optional temporal ground-truth labels if the project later wants quantitative drowsiness evaluation.

## Stage 13 Implication

Because real synchronized mouth/yawn timelines do not exist for A/B/C/D, Stage 13 must be treated as **rule-based fusion design plus offline prototype only**.

Any synthetic mouth timeline generated by Stage 13 is a design demonstration. It is not real synchronized mouth-eye fusion validation and must not be used to claim final system-level drowsiness accuracy.
